# Changes — 2026-08-29

## 1) API Base URL (`API_BASE_URL.md`)
**Spec:** admin manages `base_url` (`settings` `general/api_base_url`, type `string`); public `GET /api/v1/config/base-url` for apps; admin `GET/PUT /api/v1/admin/api-base-url` (`{base_url}`) with validation + cache clear; fallback `{APP_URL}/api/v1`.

**Frontend (Nexa Dashboard):**
- New `src/features/settings/api/apiBaseUrlApi.ts` — `getAdmin`, `updateAdmin`, `getPublic`.
- New `src/lib/apiBaseUrl.ts` — `getCachedBaseUrl`/`setCachedBaseUrl`/`getEffectiveBaseUrl`/`applyBaseUrl`/`initApiBaseUrl`; `localStorage` key `nexa-api-base-url`; fetch `/config/base-url` and apply.
- `src/lib/axios.ts` — init `baseURL` from cached value if present (`localStorage` → `env.API_BASE_URL`), else env; supports runtime override.
- `src/main.tsx` — call `initApiBaseUrl()` before render.
- `src/features/settings/pages/SettingsPage.tsx` — new card “API Base URL” (Globe icon) above General settings: shows current value (`GET /admin/api-base-url`), editable input, Save via `PUT /admin/api-base-url` → `applyBaseUrl` + invalidate `['api-base-url']` + toasts. Hint + `updated_at`.
- `src/locales/en.json` — `settings.apiBaseUrl.*`.

**Server:** `git pull origin dev && php artisan db:seed --class=SettingsSeeder` or auto-create on first admin update; no frontend migration.

## 2) Show on Home (`SHOW_ON_HOME_CATEGORIES.md`)
**Spec:** `show_on_home` boolean on `categories` and `business_categories` (default `true`; `is_active=false` hides regardless); admin `POST/PUT` accept `show_on_home`, `GET ?show_on_home=1|0` filter, response includes `show_on_home`; customer `GET /customer/home` returns `data.categories` (roots filtered) + new `data.store_categories` (from `business_categories`).

**Frontend:**
- Types `src/features/categories/api/categoriesApi.ts` / `businessCategoriesApi.ts` — add `showOnHome`/`show_on_home` with `?? true` default; `mapBackend*` updated; `getPageData` accepts `show_on_home?: number`; `create`/`update` accept `show_on_home?: boolean`.
- Forms `CategoryFormPage.tsx` / `BusinessCategoryFormPage.tsx` — new toggle “Show on home” (default `true`), persisted via `show_on_home`.
- List `CategoriesPage.tsx` — new filter `homeFilter` (`all/shown/hidden` → `show_on_home` param, `queryKey` includes it, resets `page`); search+sort bar now has Home filter + Sort; list items show badge `Shown on home` / `Hidden on home` (Eye/EyeOff, purple/gray) alongside Active.
- `src/locales/en.json` — `categories.form.showOnHome`, `categories.businessForm.showOnHome`, `categories.showOnHome/hiddenOnHome`, `categories.filter.*`.

**Server:** `php artisan migrate` required (adds `show_on_home` columns).
